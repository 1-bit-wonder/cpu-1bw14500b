# MC14500B CPU Simulator

This project is a complete, interactive simulator for the Motorola MC14500B, a 1-bit Industrial Control Unit (ICU), written in Rust. It provides a command-line interface to load and execute programs written for this unique processor.

## Features

- **Full Instruction Set:** Implements all 16 instructions of the MC14500B processor.
- **Interactive TUI:** A friendly terminal user interface allows you to select which program to run and for how many cycles.
- **File-Based Programs:** Programs are loaded from simple, human-readable text files.
- **Extensible:** Easily add new programs by creating new text files in the `programs` directory.
- **High-Quality Code:** The codebase is formatted with `rustfmt`, linted with `clippy`, and includes a comprehensive test suite with `cargo test`.
- **Well-Documented:** All public APIs are documented, and the code is structured for clarity.

## Getting Started

### Prerequisites

You must have the Rust toolchain installed. You can install it from [rustup.rs](https://rustup.rs/).

### Running the Simulator

1.  Clone this repository.
2.  Navigate to the project directory in your terminal.
3.  Run the interactive simulator with the following command:

    ```sh
    cargo run
    ```

## Usage

When you run the program, you will be presented with two interactive prompts:

1.  **Program Selection:** A list of available programs found in the `programs/` directory will be displayed. Use the arrow keys (`↑` and `↓`) to navigate and `Enter` to select a program.
2.  **Cycle Count:** After selecting a program, you will be asked for the number of simulation cycles to run. You can enter a number or press `Enter` to accept the default of 10.

The simulator will then execute the program and print the final vector of any outputs generated by `STO` or `STOC` instructions.

## Writing Programs

Creating a new program is simple:

1.  Create a new `.txt` file inside the `programs/` directory (e.g., `my_program.txt`).
2.  In this file, write one opcode mnemonic on each line. The parser is case-insensitive, and empty lines are ignored.
3.  The name of the file (without the `.txt` extension) will be used as the program name in the selection menu.

For example, to create a program that loads a `1` and stores it, your `programs/my_program.txt` would contain:

```
LDC
STO
```

## MC14500B Instruction Set

| Binary | Opcode | Operation                                  |
| ------ | ------ | ------------------------------------------ |
| 0000   | NOPO   | No change in registers                     |
| 0001   | LD     | Load Result Reg. Data                      |
| 0010   | LDC    | Load Complement Data                       |
| 0011   | AND    | Logical AND                                |
| 0100   | ANDC   | Logical AND Complement                     |
| 0101   | OR     | Logical OR                                 |
| 0110   | ORC    | Logical OR Complement                      |
| 0111   | XNOR   | Exclusive NOR                              |
| 1000   | STO    | Store                                      |
| 1001   | STOC   | Store Complement                           |
| 1010   | IEN    | Input Enable                               |
| 1011   | OEN    | Output Enable                              |
| 1100   | JMP    | Jump                                       |
| 1101   | RTN    | Return                                     |
| 1110   | SKZ    | Skip next instruction if result reg=0      |
| 1111   | NOPF   | No change in Registers                     |
